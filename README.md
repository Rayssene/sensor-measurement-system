# Sensor Measurement & Data Analysis System

## Overview
This project focuses on developing a small mechatronic measurement system that combines sensor technology, embedded programming, and data analysis.

The goal is to acquire sensor measurements using a microcontroller, transfer the data to a computer, and analyze the results using Python.

## Objectives
- Read and process sensor measurements
- Implement embedded software in C/C++
- Transfer measurement data to a computer
- Visualize and analyze data using Python
- Document the hardware, software, and testing process

## Technologies
- **Microcontroller:** Arduino
- **Programming:** C/C++, Python
- **Data analysis:** Python, Matplotlib
- **Hardware design:** Wiring diagrams and circuit documentation
- **Version control:** Git and GitHub
